# Project Notes

# Purpose Audience:
- Customers and potential clients for a nailshop looking to get mani and pedicure services done. Age groups: middle aged(25) - older women

# Languages
- Can be chosen on top of the main page
- German as default
- English as a secondary option
- Vietnamese as the third option

# Pages
- Main/Homepage with gallery (assortment of pictures uploaded from the public dir), reviews(added manually), about-information, contact and a booking appointment button that leads you to the contact page
- Contact page containing credentials, adress, a button for calling the number and a button for booking an appointment that leads you to a page that lets you fill out a form that is then submitted and shown to only to the owner (implementation and storing of data still unclear)
Customers should be encouraged to call the number for any issues or to book an appointment because those people will be prioritised
- Booking appointment page where you can fill out the form (asks for name, phone number and a text containing what it is they want done)
- Price list page where we manually enter the prices from a json

# Purpose
- The website is supposed to attract and inform customers of the provided service and its excelent quality. Gives them a docking point for contacting the shop and booking appointments

# Visual Direction
- Sleek and neat, with a luxurious but homey feeling directed for the target audience
